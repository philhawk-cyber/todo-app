# TODO アプリ

ビルド不要・依存パッケージなしの素の HTML / CSS / JavaScript で作った TODO アプリです。
タスクはブラウザの `localStorage` に保存されるため、ページを閉じても残ります。

## 使い方

`index.html` をブラウザで開くだけです。

```sh
# 例: 簡易サーバーで開く場合
python3 -m http.server 8000
# → http://localhost:8000
```

## 機能

| 操作 | やり方 |
| --- | --- |
| 追加 | 入力欄に文字を入れて Enter（または「追加」ボタン） |
| 完了 / 未完了 | 左のチェックボックス |
| 編集 | タスク名をダブルクリック → Enter で確定 / Esc で取消 |
| 削除 | 行にマウスを乗せて「×」／編集で空にしても削除 |
| 絞り込み | フッターの「すべて / 未完了 / 完了」 |
| 完了をまとめて削除 | フッターの「完了を削除」 |

- OS のダークモード設定に追従します。
- 複数タブを開いていても内容が同期します。

## ファイル構成

```
index.html   マークアップ
styles.css   スタイル（CSS 変数でライト/ダーク対応）
app.js       ロジック（IIFE + localStorage 永続化）
```
